## How I approach work

- Start with the user's task and make the next action clear.
- Describe a problem with steps, expected behavior and actual behavior.
- Keep fictional examples separate from customer information.
- Make limitations visible so another person can assess the work fairly.

These samples use **JavaScript, HTML/CSS, Node.js and Playwright**. Each repository explains what it demonstrates, how to run it and what it does not yet implement.
